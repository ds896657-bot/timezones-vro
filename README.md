# 🌍 World Clock

A modern, dark-themed world clock and time zone dashboard that lets you track the current time across multiple cities in a clean, responsive interface.

## ✨ Features

- 🕒 **Live clocks** — view the current time across different time zones.
- 🌎 **Multiple cities** — keep track of time in different parts of the world.
- ↕️ **Drag-and-drop reordering** — arrange your clock cards to your preference.
- 🌙 **Modern dark interface** — a clean, easy-to-read dashboard.
- 📱 **Responsive design** — use the web version on different screen sizes.
- 💻 **Desktop app** — a Windows version built with Electron.
